# 供应商页面实施与验收

2026-10-18（Phoenix）。供应商界面及后端联动已在本地实现，未发布到搭建服务器。PLC 数据采集和组态图按用户要求暂缓。

## 页面与操作

入口：功能管理 → 采购管理 → 供应商，路由 `/functions/procurement/suppliers`，页面授权 ID 为 `procurement-suppliers`。

- 先选择授权公司，再读取包含区域和全部公司继承的供应商；名称、编码或登记标识搜索，按最终可用状态筛选，支持编码及更新时间排序、分页。筛选和页码保存在 URL。
- 详情分公共资料、适用来源和状态、本公司设置；公共身份、供应商全局状态、本公司状态及最终可用状态分别展示。继承供应商按 partnerId + subjectId 打开，不为查看创建公司覆盖记录。
- 新建默认适用所选公司。公共资料编辑与本公司备注编辑分别授权；备注和历史原因使用可展开长文本。
- 适用范围可选全部项目公司，或区域与指定公司的并集；区域包含下级，全部包含以后新增的项目公司，总部/共享服务主体须明确选择。多选跨搜索和分页保留，失效已选项保留标识并允许人工核对。
- 全部公司停用修改供应商角色策略，本公司停用仅修改本公司覆盖；全局恢复保留各公司原有停用。本公司恢复不能绕过全局停用。全局停用期间仍可修改备注而保留原本公司状态，最终可用状态继续停用。
- “公共资料与适用范围”目录用于维护不适用当前公司的供应商，以及恢复此前移出范围的资料；有范围维护权但没有公司列表读取权的人员也能使用该目录。
- 公共资料、公司设置及适用范围分别记录分页历史及变更前后值。没有删除按钮。

新建、编辑和范围维护使用路由对话框，详情和公共目录使用子页面，启停用独立确认对话框。关闭恢复直接父视图和原筛选。提交校验必填项并聚焦首项，失败保留输入；唯一值冲突允许修改后重交，只有版本冲突提供确认放弃草稿后加载最新记录。保存时禁止取消和重复提交。成功响应立即写入当前缓存后关闭表单，后台刷新失败仍保留已确认保存的数据；403/404 给出返回路径，记录不存在时禁止重复提交。UUID v4 请求键使用 getRandomValues，适配局域网 HTTP，并在相同输入重试时保持不变。

## 权限与增量初始化

页面权与 `procurement.suppliers` 的 read/create/updateIdentity/updateRelationship/configureApplicability 业务权独立。行编辑入口使用服务端按动作数据库策略计算的能力提示；每次实际写入仍独立核对权限、字段、公司范围、版本和生命周期。原 supplierLinks 接口继续保留；页面通过适用范围扩围，不借普通公司关联扩大业务范围。

新增 seed `202610170006_supplier_page_defaults`，仅给四个已有供应商模板补缺失页面入口，保留管理员明确配置，不改变公司范围，不为真实人员分配角色。现有材料、人事和组织页面 ID 均保持。

页面联动补充：supplierCompanies/:id、supplierCapabilities/:id、supplierScopeIdentities（含单条）和 supplierScopeReferences。范围引用可读取已停用但仍有权查看的已选项标签。公司列表 supplierAvailability 增加最终状态筛选与编码/更新时间排序，更新时间取身份、策略及公司覆盖最近变更。
