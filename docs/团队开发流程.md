# 部门协作开发流程（A 路线：一个仓库，按模块归属）

集团 ERP 是**一个仓库、一个应用**。各部门在自己模块的目录里改，通过分支和 PR 汇入，不靠系统权限隔离代码。

## 1. 谁能改什么

| 部门 | 自己的目录 | 只能看、不要改 |
| --- | --- | --- |
| 组织 / 人力 | `client/pages/organization/`、`client/pages/people/`、`server/providers/organization*.ts`、`server/providers/people*.ts` | 其它部门的目录 |
| 采购 | `client/pages/procurement/`、`client/pages/suppliers/`、`server/providers/procurement.ts`、`server/providers/supplier*.ts` | |
| 仓储 | `client/pages/materials/`、`server/providers/material*.ts`、`server/providers/inventory*.ts` | |
| 领用 | `client/pages/requisitions/`、`server/providers/requisitions.ts` | |
| 销售 | `client/pages/execution/`、`client/pages/customers/`、`server/providers/execution*.ts` | |
| 安环 / 生产 / 运营 / 资产 | 各自的 `client/pages/<模块>/` 与 `server/providers/<模块>*.ts` | |
| 平台组 | `client/layouts/`、`client/routes.ts`、`client/components/`、`server/app.ts`、`config.yml`、`database/main/migrations/` | 只有平台组能改，改之前先知会 |

浏览器里看到的「职能平台」模块入口在 `client/pages/home/` 和 `client/module-manifest.ts`，属于平台组。

跨模块的公共代码（server/providers 下的 `*-model.ts`、`*-service.ts` 被多个模块复用）改动前先在群里说一句，由平台组定。

## 2. 分支怎么开

从最新的 `master` 切，命名带上部门：

```bash
git checkout master && git pull
git checkout -b procurement/order-approval
```

- `<部门>/<一句话>`，例如 `hr/contract-reminder`、`warehouse/transfer-ui`
- 一个分支只做一件事；超过 20 个文件拆开
- 不要直接在 `master` 上提交（分支保护开了会被拒）

## 3. 提交前必须过

```bash
npx tsc --noEmit                          # 客户端
npx tsc -p tsconfig.server.json --noEmit  # 服务端
```

改了表结构还要跑：

```bash
npx nocobase db apply --dry-run
```

改了人事、权限相关逻辑，跑 `npx vitest run -c vitest.logic.config.ts tests/logic/`。

## 4. 提 PR

- 标题：`<模块>: <做了什么>`
- 用仓库自带的 PR 模板填：改了什么 / 涉及模块 / 怎么验证 / 上线注意 / 回滚方式
- 评审人：`CODEOWNERS` 会自动带上模块负责人；至少 1 人批准
- 平台组会看：有没有动 migrations、有没有动公共文件、有没有动权限

## 5. 合并与上线

1. 评审通过、检查变绿 → 合并到 `master`
2. 平台组构建镜像 / 重启服务（部门没有生产部署权限，只能申请）
3. 上线后部门自己在本地点一遍关键页面

需要紧急修复时也走 PR，只是评审可以口头先过、事后补记录。

## 6. 常见坑

- **别改 `pnpm-lock.yaml` 之外还手动改 `node_modules`**：CI 会不一致
- **迁移文件一旦合并就不能改**：要改就新加一个
- **`client/locales/*.ts` 被多个目录共用**：只加自己模块的键，别删别人的
- **同一文件多部门同时改**：先到先得，后到的 rebase；冲突拿不准找平台组
