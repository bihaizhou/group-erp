## 0. 结论摘要

安环不是“事故登记本”，而是炉渣处理项目安全、环保、职业健康的事实入口：

1. **安全**：事故/未遂、隐患、检查、整改、作业票、承包商安全、培训、证书。
2. **环保**：排放监测、超标整改、危废产生/贮存/转移/处置、排污许可、环保设施运行。
3. **职业健康**：危害因素检测、职业健康体检、防护设施和告知。
4. **合规**：证照到期、法规台账、应急演练、整改闭环。

运营只读安环汇总，不重复建 HSE 台账；生产维修涉及动火、受限空间、高处、临时用电、吊装等作业时，必须先取得安环作业票，生产不能绕过。

首期按“能少不多”收敛：只做**事件、隐患、证照、总览**四件事，先把“登记—整改—验收—到期提醒”跑通。

- 检查发现的问题不建独立检查模块，直接登记为隐患，来源选“检查发现”。
- 作业票 P1 先用纸质或线下审批，不做好几级电子流；等生产模块上线、维修工单需要卡票时再做“作业报备”。
- 培训先并入证照/人员证书，不建培训课程、学时、考试。
- 排放、危废、承包商安全放 P2；职业健康、应急、移动巡检放 P3。
- 不做完整 EHS 平台，不接在线监测探头，不替代法务办证。

### 0.2 收敛原则（v1.2）

民营企业的执行难点不在“功能不够”，而在“填表太多、审批太长、没人维护”。本模块按以下五条收敛：

1. **一张表能解决的不建两张**：检查、巡检发现的问题统一进隐患；培训证书统一进证照。
2. **一个页面能完成的不拆三个**：登记、整改、验收都在列表/弹窗完成，不做多层详情页。
3. **审批不超过两级**：项目负责人确认即可；只有重大隐患、重大事故才升级到集团。
4. **默认值优先**：公司、日期、来源、等级都有默认值，现场人员只填“在哪、什么问题、谁负责、什么时候改完”。
5. **统计只留能触发动作的指标**：未闭环事件、损工事件、未关闭隐患、逾期隐患、90 天内到期证照；不堆图表。

“作业票、检查、培训、排放、危废”不是不做，而是等有真实使用场景再开，避免上线即空转。

### 1.2 模块边界

| 事项                 | 归属            | 安环模块的角色                                                    | 不做什么                           |
| -------------------- | --------------- | ----------------------------------------------------------------- | ---------------------------------- |
| 事故、未遂、隐患     | 安环            | 唯一录入、调查、整改、验证、关闭                                  | 不替生产改班报/设备事实            |
| 检查、作业票         | 安环            | P1 检查发现直接进隐患；作业票先用纸质，生产模块上线后再做电子报备 | 不建维修工单、不派生产工           |
| 排放、危废、环保设施 | 安环            | 监测台账、超标整改、危废联单、许可执行                            | 不做在线监测平台、不做环境工程改造 |

| PPE、应急物资        | 仓库            | 定标准/最低库存；仓库收发存                                       | 不另建仓库、不记库存余额           |

| 证照办理             | 法务行政 + 安环 | 安环台账、到期提醒、技术资料                                      | 不替代法务提交/领取                |
| 工伤/薪酬            | 人事 + 财务     | 提供事故/伤情事实；人事办工伤/假勤                                | 不算工资、不算赔偿                 |
| 运营                 | 运营            | 只读事故、隐患、排放、危废、证照、培训汇总                        | 不建 HSE 台账、不签发作业票        |
| 公司发展             | 公司发展        | 新项目安评/环评/建设期 HSE 资料移交                               | 不重写项目立项/投资                |

**边界原则**：安环是安全、环保、职业健康事实的唯一入口；生产、人事、仓库、采购各自管自己的主数据；运营只读汇总和督办。

### 1.3 三条硬规则

- **无票不作业**：动火、受限空间、高处、临时用电、吊装、断路、挖掘等高风险作业，没有有效作业票不得开工；生产维修工单必须引用作业票。
- **不闭环不算完**：事件/隐患/超标必须有原因、措施、责任人、期限、验证；只有“已整改”没有验证，不算关闭。
- **不拿估算充数**：没有监测/台账的数据显示“未接入/缺失”，不把 0 当达标，不把“没上报”当“没发生”。

## 2. 关键设计决策

### D1 安环独立成模块，运营不再做“手工安环占位”

- 安环模块拥有事件、隐患、检查、作业票、排放、危废、证照、培训、职业健康、应急等事实表。
- 运营不建 `opsHse*` 表，只通过安环只读服务取聚合，落 `opsDailyRollups.metrics.hse`。
- 安环目标（事故为零、隐患按期整改率等）由安环维护；运营只展示目标/实际，不另建一套安环目标。

### D2 作业票与生产维修工单强关联

- 生产维修工单需要高风险作业时，发起安环作业票；作业票批准后才允许开工。
- 作业票记录 `linkedMaintenanceOrderId`；生产工单显示“待票/已批准/已过期/已关闭”，不能把“已申请”当“已批准”。
- 作业票到期自动失效；需要延长必须重新确认气体检测和安全措施，不能只改时间。
- 承包商作业票必须关联承包商安全资质/入场培训；没有资质不能开票。

### D3 环保按“许可限值 → 监测 → 超标 → 整改 → 复查”闭环

- 每个排放口/参数有许可限值、监测频次、监测方式（在线/手工/委托检测）。
- 超标自动生成整改任务，关联原因、措施、期限、复查；未复查不能关闭。
- 在线监测只做数据接入/人工复核，不直接对外报送；执行报告仍按监管要求编制。

### D4 危废按“产生 → 贮存 → 转移 → 处置”台账闭环

- 危废分类、代码、产生量、贮存量、转移量、联单号、接收单位、处置方式全部留痕。
- 转移必须关联有资质接收单位和联单；联单未回执，台账标“在途/未闭环”。
- 危废库存与一般固废分开；不能把危废混入砂料/尾渣。

### D5 证照/证书统一到期日历

- 企业证照（排污许可、危废、消防、安全等）和人员证书（特种作业、安全员、危废管理、叉车、电工、焊工等）统一登记。
- 到期前 90/60/30 天分级提醒；过期自动标红并进运营风险卡。
- 证照办理归法务行政，安环维护技术台账和到期提醒；两边不各记一套。

### 3.3 首期 MVP

P1 只做“能闭环”的最小集：

- 事件/未遂登记 → 调查 → 整改 → 验证 → 关闭。
- 检查 → 发现问题 → 转隐患 → 整改 → 验证 → 关闭；逾期升级。
- 作业票申请 → 气体检测/措施 → 审批 → 开工 → 关闭/到期；与生产维修工单关联。
- 企业证照/人员证书登记 → 到期提醒；培训记录。
- 安环总览 + 我的待办 + 运营只读摘要。

不做：在线监测探头接入、危废联单电子对接、职业健康体检系统、应急指挥、承包商门户、移动 App（先用响应式页面）。

## 4. 核心流程

> 本节是完整目标流程；P1 收敛版只实现 4.1 事件、4.2 隐患（检查发现直接进隐患）、4.6 的证照到期。4.3 作业票、4.4 环保、4.5 危废、4.7 职业健康均按 0.2 延后，不阻塞上线。

### 4.1 事件/事故

1. 任何人可报：时间、地点、单元、类型、严重程度、伤情/释放、现场处置、照片。
2. 安环分级：未遂/急救/损工/严重/环境事件；严重事件立即停工、上报、保护现场。
3. 调查：原因分析（人/机/料/法/环/管理）、责任、纠正/预防措施、期限、责任人。
4. 整改：措施完成 → 安环验证 → 关闭；严重事件需要厂长/安环总监审批。
5. 联动：工伤/假勤给人事；损失/赔偿给财务；停机给生产；运营只读汇总。

状态：`reported → investigating → action → verifying → closed`；作废需原因，不物理删除。

### 4.2 隐患/检查

- 检查计划：日常/专项/季节性/节前/承包商；检查表可按区域/设备配置。
- 发现问题的处理：立即整改 / 限期整改 / 转隐患 / 停工。
- 隐患分级：重大/一般；重大隐患必须停业整改或局部停产，按法规报告。
- 整改：措施、责任人、期限、资金；到期未完成自动逾期，升级到厂长/安环总监。
- 验证：安环或指定人现场验证；验证不通过退回整改，不能“纸面关闭”。

状态：`open → rectifying → pending_verify → closed`；逾期单独标记，不改变状态。

### 4.3 作业票

类型默认：动火、受限空间、高处、临时用电、吊装、断路、挖掘、其他。每类有：

- 申请人、作业单位/承包商、作业内容、地点、单元、设备、有效起止时间。
- 风险辨识、隔离/上锁、PPE、消防/应急措施、监护人、气体检测（受限空间/动火）。
- 审批人（按类型/风险分级）、开工确认、完工验收、关闭。
- 延期：重新确认措施和气体检测；过期自动失效。
- 关联：生产维修工单、承包商资质、培训记录、事件/隐患（如发生）。

控制：

- 申请人不能审批自己的票；高风险作业票需要安环+厂长双签（默认）。
- 气体检测超过有效期（默认 30 分钟）不能开工；作业中断超时重新检测。
- 无票作业被检查发现，记违章并进承包商/责任人考核。

### 4.4 环保监测/超标

- 排放口台账：废气、废水、噪声；每个口有许可限值、标准、监测频次、责任人。
- 监测记录：在线/手工/委托；数值、单位、限值、结果、报告文件。
- 超标：自动生成整改，记录原因、临时措施、整改、复查；涉及停产的联动生产。
- 执行报告：按排污许可要求生成季度/年度执行报告草稿，人工复核后报送。
- 在线监测：先接采集服务/第三方平台只读数据，不直接控制治理设施。

### 4.5 危废

- 分类/代码：按国家危废名录；企业可配置常见类别。
- 产生：称重/计量、来源、容器、标签、入库时间。
- 贮存：危废库/专区、容量、超期预警（默认 1 年，按法规）。
- 转移：联单号、接收单位资质、运输单位、转移量、日期、回执。
- 处置：处置方式、处置量、联单闭环；未回执标“在途”。
- 对账：产生 − 转移 − 库存 = 0（允许计量误差，超差说明）。

### 4.6 证照/培训

- 企业证照：排污许可、危废管理计划/备案、消防、安全、职业健康等；有效期、发证机关、责任人、附件。
- 人员证书：特种作业、安全员、危废管理、叉车、电工、焊工、有限空间作业等；人员、证书号、有效期、复审。
- 培训矩阵：岗位 → 必修课程 → 频次；记录完成时间、成绩、证书。
- 到期提醒：90/60/30 天；过期人员不能安排对应作业（默认提示+阻断高风险作业）。

### 4.7 职业健康/应急（P3）

- 职业健康：危害因素检测（粉尘、噪声、重金属等）、体检计划、异常复查、岗位调整建议；体检结果敏感，仅安环/指定医生/本人可见。
- 应急：预案、演练计划/记录、应急物资、应急事件；演练问题转整改。
- 不替代专业体检机构/消防维保系统。

## 5. 数据模型

### 5.1 通用约定

- 主键 `id` 字符串 36 位 UUID；业务编码 `code`/`permitNo` 在公司内唯一。
- 公司范围 `subjectId`；单元范围 `unitId`；查询必须带范围条件。
- 数量/浓度/限值用定点字符串（长度 25，最多 18 位整数 + 6 位小数）+ CHECK，避免 SQLite REAL 精度问题；单位单独存。
- 时间 `datetimeTz` 存 UTC，展示 `Asia/Shanghai`；业务日期用 `date`。
- 并发 `version` 乐观锁；关键动作带 `nonce` 幂等键；冲突明确提示，不自动覆盖。
- 审计 `createdBy/updatedBy/createdAt/updatedAt`；关键动作写办理历史。
- 业务记录不物理删除；作废保留，报表可追溯。
- 附件复用现有文件服务，不新建存储。

### 5.3 关键约束

- `hseIncidents`：`(subjectId, incidentNo)` 唯一；严重事件关闭必须有调查报告、整改验证、审批人。
- `hseHazards`：`(subjectId, unitId, discoveredAt, description hash)` 不强制唯一（可能重复上报），但同一地点/同一问题可合并；逾期由 `dueAt` 计算，不手工改状态。
- `hseWorkPermits`：`(subjectId, permitNo)` 唯一；`validFrom < validTo`；`status=active` 时才能关联开工；过期自动 `expired`；延期生成新版本，不覆盖原票。
- `hseCertificates`：同一持有人同一证书类型可有历史多条，但 `status=valid` 只允许一条；到期提醒按 `expiresAt`。
- `hseEmissions`：同一排放口/参数/时间唯一；超过 `limitValue` 自动 `exceed` 并生成整改。
- `hseWasteLedger`：产生/转移/库存数量不能为负；转移必须有联单号/接收单位；库存 = 产生 − 转移 − 处置（允许误差说明）。
- `hseActions`：来源删除/作废时措施保留；关闭必须有验证人。
- 所有跨公司查询必须由服务端 scope 注入，不能只靠前端过滤。

- `202610230001_hse_core`：`hseIncidents`、`hseHazards`、`hseInspections`、`hseWorkPermits`、`hseCertificates`、`hseTrainingRecords`、`hseActions`。
- `202610230002_hse_environment`：`hseEmissions`、`hseWasteLedger`、`hseContractorProfiles`。

| ------------- | ------------ | --------------------------------------------------- |
| 安环总监      | 全部授权公司 | 看全部、审重大事件/隐患、配置、导出                 |
| 安环专员      | 本公司       | 事件/隐患/检查/作业票/证照/培训日常办理             |

| 法务行政      | 授权公司     | 读证照台账、办理换证/备案                           |

- 职责分离：作业票申请人不能审批自己的票；严重事件调查人不能是直接责任人；职业健康数据只对安环负责人/指定医生/本人开放。
- 数据范围按 `subjectId` 注入；项目角色只本公司；跨公司返回 403。

## 8. 指标口径

| #   | 指标             | 建议口径                                  | 数据来源    | 频度 |
| --- | ---------------- | ----------------------------------------- | ----------- | ---- |
| 1   | 可记录事故数     | 除急救外的工伤/职业病/环境事件数          | 事件        | 月   |
| 2   | 损工事故数       | 造成缺勤的事故数                          | 事件        | 月   |
| 3   | 损工天数         | 因工伤缺勤的日历天数                      | 事件/人事   | 月   |
| 4   | 未遂事件数       | 未造成伤害/损失但可能造成的事故           | 事件        | 月   |
| 5   | 最后事故间隔天数 | 业务日期 − 最近一次损工事故日期           | 事件        | 日   |
| 6   | 隐患闭环率       | 已关闭隐患 ÷ 新增隐患                     | 隐患        | 月   |
| 7   | 隐患逾期数       | `dueAt < 今天` 且未关闭的隐患数           | 隐患        | 日   |
| 8   | 作业票异常       | 无票作业/过期作业/气体检测缺失/措施未确认 | 作业票/检查 | 月   |
| 9   | 排放达标率       | 达标监测次数 ÷ 有效监测次数               | 排放        | 月   |
| 10  | 超标次数         | 超过许可限值的监测次数                    | 排放        | 月   |
| 11  | 危废合规处置率   | 有联单且接收单位有资质的处置量 ÷ 应处置量 | 危废        | 月   |
| 12  | 危废库存量       | 期初 + 产生 − 转移 − 处置                 | 危废        | 月   |
| 13  | 证照到期数       | 未来 90 天内到期的企业证照/人员证书数     | 证照        | 月   |
| 14  | 安全培训覆盖率   | 已完成必修培训人数 ÷ 应培训人数           | 培训        | 月   |
| 15  | 特种作业持证率   | 持有效证人员 ÷ 从事特种作业人员           | 证书/人事   | 月   |
| 16  | 应急演练完成率   | 已完成演练 ÷ 计划演练                     | 应急        | 季   |

口径注意：

- 事故率需要“百万工时”分母；首期没有工时数据时只显示事故数/损工天数，不编造事故率。
- 隐患闭环率按“当期新增”还是“期末未闭”要固定；默认“当期新增”并同时显示期末未闭数。
- 排放达标率只统计有效监测；缺报/无效数据不算达标。
- 危废库存允许计量误差，超差必须说明，不静默调平。

## 9. 与运营的集成

安环是事实入口，运营只读：

- 运营总览增加“安环状态”卡：P1 显示本月事故/未遂、损工天数、逾期隐患、作业票异常、证照到期；P2 加排放超标/危废。
- 运营主题分析增加“安环”主题：安全（事件/隐患/作业票/培训/证书）、环保（排放/危废/许可，P2）。
- 运营单元详情增加“安环”标签页：只读摘要 + 跳转安环。
- `opsDailyRollups.metrics.hse` 建议字段：
  - `incidents`、`lti`、`nearMiss`、`lostDays`
  - `hazardsOpen`、`hazardsOverdue`、`hazardClosureRate`
  - `permitsActive`、`permitViolations`、`permitsExpired`
  - `emissionExceedances`、`emissionComplianceRate`
  - `hazardousWasteStock`、`hazardousWasteTransferred`
  - `certificatesExpiring90`
  - `trainingCoverage`
- 排放/危废字段 P2 才接；未接入时为空并标“未接入”，不显示 0。
- 运营不建 HSE 表；只读 API `GET /api/hse/operations-summary`，服务端 scope 过滤。
- 浏览器不直连 HSE；运营服务端调用该接口，再以 `/api/operations/units/:id/hse` 暴露给前端，两层鉴权。
- 安环目标由安环维护；运营只展示，不另建一套目标。
- 职业健康只给聚合（体检覆盖率/异常复查率），不把个人体检结果给运营。

## 10. 实施阶段

> 本节保留完整路线，用于后续排期；实际执行以 0.2 收敛原则为准。P1 只做已落盘的事件、隐患、证照、总览；P2/P3 等真实场景出现再启动，不按月份硬排。

> 工作量为粗略人周，用于排优先级，不是承诺工期；实际取决于业务确认、证照/许可资料和现场配合。

### P0 口径与准备（约 1 周，业务为主）

- 确认安环范围：安全+环保+职业健康，还是先安全+环保。
- 确认作业票类型、审批人、气体检测要求、有效期。
- 确认排放口/参数/限值/监测频次，收集排污许可、环评、危废管理计划。
- 确认危废类别、贮存期限、接收单位、联单流程。
- 确认企业证照/人员证书清单、责任人、到期提醒规则。
- 确认事件/隐患分级、整改期限、逾期升级规则。
- 输出《安环指标字典》《作业票规则》《证照清单》《危废台账规则》。

**通过条件**：上述条目有书面结论；没有结论的按“默认建议”标注，不阻塞 P1 的事件/隐患/作业票。

### P1 安环骨架（约 3–4 周）

- 安环总览、事件/未遂、隐患/检查、作业票、证照/培训。
- 事件 → 调查 → 整改 → 验证 → 关闭；隐患逾期升级。
- 作业票与生产维修工单关联；到期/无票校验。
- 证照/证书到期提醒；培训记录。
- 运营只读摘要 API + 总览安环卡。

**通过条件**：事件/隐患全流程可追溯；作业票无票不能开工；证照到期能提醒；运营卡片与安环明细一致；无权限返回 403。

### P2 环保与承包商（约 3–4 周）

- 排放口/限值/监测/超标整改/执行报告草稿。
- 危废产生/贮存/转移/联单/处置对账。
- 承包商安全资质、协议、入场培训、违章。
- 检查表模板、移动端适配（响应式优先）。

**通过条件**：超标能生成整改并复查；危废台账平衡；联单未回执能提示；承包商无资质不能开票。

### P3 职业健康与应急（约 2–3 周）

- 职业危害因素检测、体检计划、异常跟踪。
- 应急预案、演练、物资、应急事件。
- 安环报表、趋势、对标；与运营主题分析打通。

**通过条件**：体检数据权限正确；演练问题能转整改；运营只看到聚合。

### 不建议首期做

- 完整 EHS 平台/安全标准化全套。
- 在线监测探头直连、治理设施自动控制。
- 危废联单与监管平台电子对接。
- 职业健康体检机构系统、病历管理。
- 应急指挥调度、视频 AI 识别。
- 承包商门户/APP。
- 安全绩效工资/安全积分商城。

## 11. 验收与测试

> P1 验收只看四件事：事件能闭环、隐患能整改验收、证照到期能提醒、运营能取到 5 个聚合指标。作业票/环保/危废/职业健康测试随对应阶段再补。

| 类型     | 覆盖                                                         |
| -------- | ------------------------------------------------------------ |
| 状态机   | 事件调查/关闭、隐患整改/验证、作业票审批/开工/过期、证照到期 |
| 作业票   | 无票开工、申请人自批、气体检测过期、延期、承包商无资质       |
| 环保     | 超标生成整改、复查关闭、缺报不算达标、执行报告草稿           |
| 危废     | 产生/转移/库存平衡、联单未回执、接收单位资质                 |
| 权限     | 跨公司 403、职业健康敏感数据、运营只读、承包商只看自己       |
| 组件     | 总览卡、事件/隐患列表、作业票表单、证照到期、空态/逾期态     |
| 浏览器   | 厂长 vs 安环 vs 值班长；作业票全流程；隐患逾期升级；运营跳转 |
| 数据质量 | 缺报、过期、未闭环、证照过期、危废库存异常                   |

## 12. 风险与对策

| 风险                 | 影响                 | 对策                                                   |
| -------------------- | -------------------- | ------------------------------------------------------ |
| 安环变成“填表系统”   | 现场不用、数据失真   | 表单最短化、移动端优先、与作业票/维修工单绑定          |
| 作业票被绕过         | 高风险作业失控       | 生产工单硬校验；无票不能开工；检查违章记分             |
| 证照/许可资料不全    | 无法配置限值/到期    | P0 收集许可/环评/危废计划；缺失标“待补”，不编造        |
| 职业健康数据泄露     | 隐私/合规风险        | 字段级权限；只给本人/指定医生/安环负责人；运营只看聚合 |
| 与生产/人事/仓库重复 | 两套台账、数据对不上 | 边界表 + 单一事实来源；接口只读                        |
| 在线监测数据质量差   | 误报/漏报            | 先人工复核；标记无效数据；不自动对外报送               |
| 法规变化             | 限值/流程过期        | 类型/限值/提醒可配置；定期复核                         |
| 范围蔓延到完整 EHS   | 首期做不完           | MVP + “不建议首期做”清单；单独立项                     |

## 13. 需要确认的问题

### 阻塞 P1

1. **范围**：安环首期是否只做安全+环保，职业健康放 P3？默认建议：是。
2. **作业票类型/审批**：动火、受限空间、高处、临时用电、吊装、断路、挖掘是否都要？谁审批？默认建议：全要；安环+厂长双签高风险票。
3. **事件/隐患分级**：重大/一般如何定义？逾期升级给谁？默认建议：按法规+企业制度，逾期 3 天升厂长、7 天升安环总监。
4. **证照清单**：排污许可、危废、消防、安全、职业健康等哪些由安环台账管？谁负责换证？默认建议：安环台账，法务行政办理。
5. **现有资料**：排污许可、环评、危废管理计划、应急预案、特种作业人员清单能否提供？默认建议：P0 收集，缺失标“待补”。

### 影响 P2/P3

6. **排放口/参数**：废气、废水、噪声分别测什么？在线还是手工？默认建议：先手工/委托，P2 接在线只读。
7. **危废范围**：废油、废电池、废灯管、沾污物、化验废液是否都有？接收单位是谁？默认建议：先建常见类别，按联单闭环。
8. **承包商**：外委维修/运输/保洁是否纳入安全资质和入场培训？默认建议：纳入，P2 做。
9. **职业健康**：体检机构、危害因素检测机构、数据可见范围？默认建议：P3，最小权限。
10. **运营指标**：安环在运营首屏显示哪些？默认建议：P1 事故/未遂、逾期隐患、作业票异常、证照到期四项；P2 加排放超标/危废。

## 附录 A：作业票类型与字段

默认类型：动火、受限空间、高处、临时用电、吊装、断路、挖掘、其他。

必填：申请人、作业单位/承包商、作业内容、地点/单元/设备、有效起止、风险辨识、隔离/上锁、PPE、消防/应急措施、监护人、气体检测（适用时）、审批人、开工确认、完工验收。

## 附录 B：危废台账字段

废物名称、类别/代码、来源、产生量、产生日期、容器/标签、贮存位置、贮存量、转移量、联单号、运输单位、接收单位/资质、转移日期、处置方式、处置量、回执、库存。

## 附录 C：证照/证书清单（默认）

企业：排污许可证、危废管理计划/备案、消防验收/备案、安全生产相关证照、职业健康相关备案、环评批复、应急预案备案。

人员：特种作业操作证（电工、焊工、高处、有限空间等）、叉车、起重、安全管理、危废管理、消防设施操作员。

## 附录 D：术语

- **未遂事件**：未造成伤害/损失，但可能造成事故的事件。
- **隐患**：可能导致事故/环境事件的人、机、料、法、环、管理缺陷。
- **作业票**：高风险作业前，对风险、措施、气体检测、监护人、审批的书面确认。
- **LOTO**：挂牌上锁，防止设备意外启动/能量释放。
- **危废**：列入国家危险废物名录或具有危险特性的废物。
- **联单**：危废转移的法定跟踪单据，记录产生、运输、接收、处置。
- **排污许可**：企业排放污染物的法定许可，含排放口、因子、限值、监测要求。
