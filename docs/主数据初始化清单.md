## 2. 录入顺序与页面

1. **公司**：`/organization/subjects/new`
2. **生产单元**：`/organization/units/new`（类型选公司下属单元；名称写产线名）
3. **仓库**：`/functions/warehouse/settings/warehouses/new`
4. **物料 SKU**：`/functions/warehouse/materials/new`（基本单位选吨）
5. **生产属性与物料清单**：`/functions/production/setup`
   - 选生产单元；
   - 填产线编码、设计产能、投产日期；
   - 逐行添加该产线处理的物料（SKU 从物料中心选）：炉渣等选“原料”，金属/砂等选“产品”或“副产品”，药剂/钢球等选“辅料”；产品和副产品指定默认入库仓库。
6. **岗位**：`/organization/positions/new`
   - 所属单元选该产线；
   - “生产类别”选“生产岗位”；
   - 非生产岗位选“非生产岗位”。
7. **员工与任职**：
   - 员工：`/functions/personnel/employees/new`
   - 主职任职：`/functions/personnel/assignments/new`（类型选主职，岗位选上面的生产岗位，开始日期填真实日期）
8. **验证排班/填报**：
   - 排班：`/functions/production/schedules`
   - 填报：`/functions/production/report`（按账号自动带出公司、岗位、填写人；一次提交班报/到勤/停机/加班）
   - 班报记录：`/functions/production/shift-reports`
   - 入库：`/functions/warehouse/inbounds`

## 3. 试点验收顺序

- [ ] 公司、单元、仓库、SKU 能选到；
- [ ] 生产单元档案保存成功，物料清单至少包含 1 行原料和 1 行产品；
- [ ] 岗位显示“生产岗位”，生产报表页显示公司/岗位/姓名，应到名单出现该岗位人员；
- [ ] 保存并发布一条排班，填报页只显示已排人员；
- [ ] 建一条班报，按物料清单填数量与期末实盘（实盘旁边显示账面库存与差异），确认成功；
- [ ] 生成仓库生产入库草稿，仓库入库单能查到；
- [ ] 仓库过账后，班报显示“已过账”，运营总览产量/库存增加；
- [ ] 运营总览的销售、采购、在岗人数、安环、停机卡片均有数据或明确空态。

## 4. 我不替你编的部分

- 公司全称、产线名称、仓库名称、SKU 编码、岗位名称、员工姓名及任职日期，必须来自现场。
- 组织主体和项目档案的层级如与现行组织架构不一致，先说明，再决定是否调整主档，避免双主档。
- 试点跑通前，不建议批量导入十几家公司；先把一条线跑顺，再复制。
